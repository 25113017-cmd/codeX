# API Sentinel — API Testing Tool

**Team Name:** codeX

**Domain:** Developer Tools / Backend Engineering

## 1. Project Overview
API Sentinel is a web-based API testing tool that helps developers send HTTP requests, inspect API responses, and identify failures.

## 2. Problem Statement
Developers need a quick way to test APIs, inspect responses, and identify errors without manually checking every response.

## 3. Proposed Solution
API Sentinel provides a simple interface for sending HTTP requests, viewing responses, and validating expected status codes.

## 4. Key Features
- Support for GET, POST, PUT, and DELETE requests
- Custom request headers
- Request body configuration
- HTTP status code display
- Response time measurement
- Response headers and body inspection
- Expected status code validation
- Basic JSON validation
